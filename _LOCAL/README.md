# LOCAL executables

Very WIP, sorta-placeholder directory: The idea is to aggregate various system-
specifc or otherwise overly general scripts I've written. Likely very rushed,
likely very unique to my own configuration and nothing else....but they've
gotta go somewhere.

Scripts specific to projects can obviously go with the project, scripts
specific to a certain configuration (say, a wallpaper manager) could go with
those dotfiles. But other scripts, like my old 'launch pipewire' or 'get
battery percentage' scripts don't have such an association.

Before, I'd hosted them within ZSH as that config would source them...but I
still don't love this considering some scripts are bash, or otherwise have some
other merit to being more "standalone."
