# Grub config
Target directory: `/etc/`

_FOR REFERENCE ONLY_

This is just a reference of modified grub configuration. Refer to the default file at install for the available options. May vary considerably per system.

Grub has a bit of an unintuitive configuration system. The official `grub.cfg` exists on the boot partition. That much alone is reasonable considering the nature of it, but it is generated by pulling from a number of different locations:

### `default/`

This directory contains a single config file which appears to specify generic options for the grub configuration generation.

_Drop-ins are also supported here via:_ `grub.d/*.conf`

### `grub.d/`

I believe that this directory specifically indicates rules for menu entries. Thus, it contains our overlay snapshot menu entries.
