# CATALYST - Personal Dotfiles Branch
For now, this branch is just the home for my personal dotfiles -- the original purpose of this repository before I began turning it into a dotfiles manager program. It's not *really* much of a branch, so arguably this isn't the best place to keep such a thing, but I really like keeping like-files in the same place.

Once the configuration file manager is complete\*, this branch will be updated to follow the expected filesystem layout for the script, and might serve as a helpful reference usage. But for now, this is just the dumping grounds for my dotfiles that can't help but change in parallel with updates to the manager.

_After such an update, this branch might be more effective as a sub-repo, but I'll plan to cross that bridge when I arrive._
